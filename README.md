## What I build

I work at the intersection of **business operations, analysis, automation, data, and software delivery**. My strength is translating a business need into a clear process, a trustworthy KPI, a useful dashboard, or a working web experience.

My background spans client research, prospecting, outreach, CRM and lead tracking, stakeholder communication, project coordination, vendor coordination, event operations, process improvement, digital strategy, analytics, and responsive web development. I am also a co-founder of **ENVEI**, a workforce-measurement platform focused on understanding how skills, education, and labour-market needs align.

> Start with the business question. Define the process. Make the data trustworthy. Build the smallest useful product. Measure the result. Document the trade-offs.
